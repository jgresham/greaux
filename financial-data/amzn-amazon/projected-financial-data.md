# Amazon Projected Financial Data

App source file: `src/pages/Amazon.jsx`

## Default Projection Inputs

| Input | Default Value | Source / Rationale |
| --- | --- | --- |
| AWS CAGR | 18% | AWS re-accelerated to 18.9% in CY2024. AI workload migration and Bedrock/Trainium adoption sustain high-teens growth. Source: Amazon earnings, Jefferies AMZN note 2024. |
| Advertising CAGR | 16% | Amazon Advertising grew 18% in CY2024; Prime Video ads add incremental inventory. Deceleration to ~16% as base grows. Source: Wall Street consensus, eMarketer ad forecast. |
| Third-Party Seller Services CAGR | 10% | Marketplace growth driven by international expansion and take-rate creep. Source: analyst consensus. |
| Subscriptions CAGR | 7% | Prime membership relatively mature in US; modest international + price-increase growth. Source: analyst consensus. |
| Stores CAGR | 5% | Online stores + Whole Foods + Other. E-commerce penetration maturing in developed markets. Source: eMarketer e-commerce forecast. |
| GAAP net margin | 12% | CY2024 was 9.3%. AWS mix shift and operating leverage across North America expected to expand margins to ~12% by 2029. Source: AWS profitability trajectory, analyst models. |
| P/E multiple | 35x | Amazon has historically traded at high P/E multiples. 35x forward earnings is a moderate base case given AWS and Advertising growth profiles. Source: Bloomberg consensus. |
| Diluted shares | 10.5B | CY2024 diluted shares ~10.5B. Amazon has not done significant buybacks historically. Source: Amazon 10-K CY2024. |
